- **Position ID**: Уникальный ID NFT-позиции

- **Tick Lower/Upper**: Границы тикового диапазона
- **Price Lower/Upper**: Границы ценового диапазона (в формате token1/token0)

- **Withdrawn Token0/Token1**: Суммы токенов, выведенных из позиции
- **Collected Fees**: Уже собранные комиссии
- **Total Fees**: Общие комиссии (собранные + несобранные)

## Формат графиков

### `charts/0xc6962004f452be9203591991d15f6b388e09e8d0_liquidity_log.png`

График с логарифмическими осями, показывающий полное распределение ликвидности по всем тикам:

- **Ось X**: Цена (token1/token0) в логарифмической шкале
- **Ось Y**: Ликвидность в логарифмической шкале
- **Красная линия**: Текущая цена пула
- **Синяя область**: Распределение ликвидности

### `charts/0xc6962004f452be9203591991d15f6b388e09e8d0_liquidity_linear.png`

График в линейной шкале, фокусирующийся на диапазоне ±20% от текущей цены:

- **Ось X**: Цена (token1/token0) в линейной шкале
- **Ось Y**: Ликвидность в линейной шкале
- **Красная линия**: Текущая цена пула
- **Зелёная область**: Распределение ликвидности

## Примечания

1. Все суммы токенов нормализованы с учётом decimals (например, для USDC с 6 decimals: 1000000 raw → 1.0 USDC)
2. Цены рассчитаны по формуле: `price = 1.0001^tick / (10^(decimals1 - decimals0))`
3. Данные сортируются по убыванию total fees для файла summary
4. Позиции с `liquidity = 0` (закрытые) исключаются из анализа
